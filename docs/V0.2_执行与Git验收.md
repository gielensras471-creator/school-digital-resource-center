## 功能自测（Windows）

1. `npm install`，`npm run dev`；打开 `http://localhost:5173`。
2. 总站点「进入书法教学」，依次选择「一年级下册→第 2 周」，检查显示「长撇」，6 个已记录的示例课程可点击选择。
3. 地址栏输入 `/calligraphy/grade/1/week/2/lesson/3`，应显示「广」，但视频框明确标识未接入。
4. 打开 `/calligraphy/grade/5/week/9`，应显示「第 9 周」，不能臆造主题或把冲突的 12 号视频误认为已导入。
5. 打开 `/calligraphy/grade/6`、`/calligraphy/grade/1/week/15`、`/random`，应显示友好 404，返回首页链接可用。
6. 浏览器历史返回/前进、网页刷新、直接打开有效深链接均可正常导航（本地 Vite 下）。
7. 使用浏览器设备模拟 320、375、390、768、1024、1440 宽度，无横向溢出；电脑端课程双栏、手机端上下布局。
8. `npm run type-check && npm run build` 均成功；`npm run preview` 可打开构建结果。

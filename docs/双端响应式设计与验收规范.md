# V0.1｜电脑端与手机端响应式设计及验收规范

日期：2026-10-28　版本：V0.1（修订）　状态：**已形成设计方案，待项目方评审**

## 一、设计原则

1. **电脑端与手机端同等支持**，既不是只有手机版，也不是电脑端简单拉伸手机页面。
2. **只开发和维护一套 Vue 3 网站**，使用响应式 CSS（Grid、Flexbox、媒体查询／容器查询）切换布局；不建两套站点或两套课程数据。
3. **相同网址在电脑、安卓、iPhone、微信中可访问**，不根据设备更改教材二维码链接；扫码直接进入周次或指定课程。
4. 页面包含：总站首页、书法首页、年级周次页、课程播放页及异常页面。不同设备共用路由、课程 ID、标题和同一批视频文件。
5. 当前只是 V0.1 低保真交互原型；真实浏览器播放、云端 HTTPS、微信兼容均属于后续版本。

## 二、主要页面双端布局对照

| 页面 | 电脑端（约 1024px 及以上） | 手机端（约 320–430px） |
|---|---|---|
| 总站首页 | 宽屏横向主视觉；书法模块卡片与未来拓展说明并排 | 主视觉文字前置；模块入口占满内容宽度，次要说明下排 |
| 书法首页 | 3 列年级卡片及右侧使用说明 | 2 列年级卡片（过窄时改 1 列），说明简化 |
| 年级周次页 | 3 列周次卡片，较窄平板可退至 2 列 | 13 周纵向列表，便于单手点击 |
| 周次播放页 | 左侧较宽的播放器；右侧课程列表，可直接点选 | **视频先出现**，课程列表排在播放器下方，2 列可触控按钮 |
| 404 / 缺失内容 | 居中提示和返回入口 | 同一内容缩排显示、按钮易点按 |

## 三、适配规则与目标宽度

- **手机：** 320px、360px、375px、390px、414px、430px（优先验证 375/390px）。
- **平板 / 小屏笔记本：** 768px、820px、1024px；根据可用空间把网格列数逐步增加，播放页可暂时纵向排布。
- **常见电脑：** 1280px、1366px、1440px、1920px；主内容设置最大宽度，防止大屏文字过散。
- **布局变化：** 以页面可用宽度为基准，原型使用容器查询约 `640px`、`920px` 两处布局切换；这是设计基线，V0.2 可微调。
- **触控操作：** 手机端核心触点约 44–48px 或更高；不用必须悬浮鼠标才能操作的功能。
- **视频：** 原型用 16:9 灰盒占位；真实视频纵横比未知，V0.3 用原生 video + `object-fit: contain` 避免裁剪关键笔画。
- **访问与可用性：** 内容没有水平溢出；文本可读、按钮可点击；键盘 Tab 有焦点，页面支持返回与刷新。

## 四、两个端共用的 URL（示例路径，不得印刷）

- `/`：资源总站
- `/calligraphy`：书法入口
- `/calligraphy/grade/1`：一年级下册周次
- `/calligraphy/grade/1/week/2`：一年级下册第 2 周视频页
- `/calligraphy/grade/1/week/2/lesson/3`：示例为“广”字的单课入口

**注意：** 原型 HTML 为便于本地双击演示，以 `#/calligraphy/...` 维护原型内部导航及浏览器历史；V0.2 正式 Vue Router 的业务路径将去掉 `#`，域名和云部署规则另行确定。单课映射在数据异常核实前不可直接用作教材印刷二维码。

## 五、V0.1 本次交付及测试

- 可交互原型：`prototype/响应式双端低保真原型.html`。
- 原型内「电脑预览 / 手机预览」按钮可以在电脑浏览器中改变展示宽度，也可以缩放浏览器窗口检查真实响应式布局。
- 模拟周次扫码直达：一年级下册第 2 周（“长撇”）；模拟单课扫码直达：同周第 3 课（“广”）。
- 截图：电脑端总站、电脑端课程播放页、手机端年级入口、手机端课程播放页，及双端概览图。
- **自动化浏览器检查：** Chromium 在 320、375、390、428、768、1024、1440px 宽度下通过页面水平溢出检查；总站到年级到周次到单课、回退与扫码模拟导航通过，未检测到页面 JavaScript 运行错误。这是**原型演示测试**，不是手机微信/真实视频兼容测试。

## 六、仍需项目方确认

- 电脑与手机两套布局是否符合预期；书法播放器电脑端左右布局、手机端上下布局是否认可。
- 学校标志与名称、主色、教材二维码粒度。
- 视频授权、域名、云账号、原始视频目录及异常文件。

**本设计确认后才能将响应式布局作为 V0.2 代码实现的验收标准。**

# V0.2.1 UI 视觉修订及验收

> 开发基线：GitHub 仓库 `gielensras471-creator/school-digital-resource-center` 的 V0.2 页面源码。此阶段是**仅 UI 的增量补丁**，没有调整课程目录、路由或视频资源映射。

## 视觉方向

- 参考成熟在线教育平台的信息层级，采用白色导航、浅灰蓝背景、品牌蓝强调、低干扰卡片。
- 使用原创 CSS / SVG 图形，无需下载第三方图片或字体，无网络依赖。
- 资源总站采用简洁横幅与资源卡片；书法模块按年级和周次浏览；视频页保持桌面左右分栏、手机上下布局。
- 首期未开放的“朗读与听力”“科学实验”只是灰色占位卡片，**不可点击**。

## 本版改变的文件

- `src/styles/global.css`：更新颜色、字体层级、组件外观、响应式规则、显式浅色背景。
- `src/components/AppHeader.vue`：蓝色书本品牌标记和简洁导航（原路由不变）。
- `src/components/AppFooter.vue`：调整预览状态文字与页脚排版。
- `src/pages/HomeView.vue`：简洁总站横幅与资源入口。
- `src/modules/calligraphy/pages/CalligraphyHomeView.vue`：五个年级卡片。
- `src/modules/calligraphy/pages/GradeView.vue`：13 周目录卡片。
- `src/modules/calligraphy/pages/WeekView.vue`：播放器占位与示例课程列表视觉调整。

## 明确未做的事

- 没有新增登录、搜索、排行榜或教师后台；没有改动 `src/router/index.ts`。
- 没有修改 `src/modules/calligraphy/data/catalog.ts`；原有一（下）第 2 周 6 个课程示例保持不变，其余周次仅有概要。
- 没有新增真实 MP4、视频时长、观看数据或上传功能。
- V0.3 和 V0.4 仍负责真实视频播放及 741 条数据导入。

## 本地验收

在项目根目录执行：

```powershell
npm run type-check
npm run build
npm run dev
```

- 电脑端：1440px、1024px；手机端：430px、390px、375px、320px；平板：768px。
- 首页：蓝白风格；“书法教学”卡片和按钮可点击；其他规划卡片不能点击。
- 年级页：一至五年级下册；对应 78 / 195 条视频目录数量。
- 周次页：二至十四周共 13 个入口，数字顺序正确，五年级主题不臆造。
- 播放页：一年级第 2 周显示 6 节示例课程，点击“广”后路由切换，正确高亮“广”，不可播放的占位状态明确。
- 任意直接输入有效周次路径、刷新及浏览器返回正常；非法年级仍进入 404。
- Chrome/Edge 调试工具中模拟深色系统模式，页面背景仍为浅灰蓝，页面无横向溢出。

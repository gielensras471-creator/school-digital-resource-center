# V0.3｜目录清单核对与视频样本说明

## 来源与统计
- 来源：用户上传的 Windows `tree /f /a` 导出 `目录结构.txt`（UTF-16 LE）。
- 文件清单：五个年级下册，65 个周次，741 条 `.mp4` 文件条目。仅为**文件名清单**，尚未核验实际视频内容、时长和编码。
- 一、二年级：每个年级 78 条；三、四、五年级：每年级 195 条。
- 源目录两层嵌套，如 `1.一（下）/1.一（下）/第二周长撇/1.长撇.mp4`，不能去掉其中一级。
- 根目录五个 `.zip` 是原始压缩包，不应与解压的 `.mp4` 重复计算。

# V0.1｜路由、课程标识与二维码规范

版本：V0.1（设计草案）　状态：**待评审**

## 1. 站点与视频分离

稳定业务 URL（供二维码使用） → Vue 课程页面 → 课程 JSON → `objectKey` → 腾讯云 COS MP4。

网站地址与视频文件地址不得混用；视频域名统一在运行配置中管理。网站第一期无需数据库、独立后端。正式域名未定，本文示意的 **URL 都是相对路径**，不具备印刷资格。

## 2. 业务路由表

| URL | 含义 | 数据要求 |
|---|---|---|
| `/` | 资源总站 | 无 |
| `/calligraphy` | 书法首页 | 1–5 年级下册 |
| `/calligraphy/grade/:grade` | 年级周次列表 | `grade` 为整数 1–5 |
| `/calligraphy/grade/:grade/week/:week` | 周次播放页 | `week` 为整数 2–14，展示该周课程 |
| `/calligraphy/grade/:grade/week/:week/lesson/:lessonKey` | 指定单课直达 | 在该年级和周次内必须唯一 |
| `/:pathMatch(.*)*` | 404 | 帮助用户回到正确页面 |

示例：`/calligraphy/grade/1/week/2`；`/calligraphy/grade/1/week/2/lesson/1`。

- 周次按整数升序排序；课程按确定后的 `displayOrder` 整数排序，不直接按文件名字符串排序。
- 路由中的 `grade`、`week` 必须先验证范围；无此资源返回友好缺失页，不将错误 ID 误映射到其他视频。
- 课程直达页复用周次播放页组件，并预选目标课；无需单独的第二套播放器。
- SPA 正式部署时必须支持深层路径首次加载及刷新回退；具体托管方式在 V0.5 验证。

## 3. 课程标识设计

- **周次稳定 ID**：`calligraphy-g1-w02`（一下一二周；仅作为示例格式）。
- **单课稳定 ID**：`calligraphy-g1-w02-01`，对一般无歧义的第 1 个源序号，可使用 `lessonKey: "1"`。
- 必须区分三个字段：`originalSequence`（从文件名提取，不擅自改）、`displayOrder`（确认后用于界面排序）、`lessonKey`（二维码和路由永久引用，发布后不得随意改）。
- **已知冲突**：五年级下册第 9 周存在 `12.通.mp4` 与 `12.阳.mp4`、缺少源序号 11。不能直接让两个文件使用 `/lesson/12`；导入时须保留两条原始记录并标记 `sequence_conflict`。在校方核实之前，**这两节课的正式单课 URL 不冻结**。
- 可在临时数据里通过不同的内部 ID（如文件路径哈希/持久化清单键）区分冲突文件；正式 `lessonKey` 必须经校对后固化，一旦印刷不得重新编号导致错链。异常情况下允许设置与序号无关的永久键，不能靠随时变化的数组索引作为长期身份。
- 四年级第 4 周 `4.表.mp4`、`9.表.mp4` 标题相同，**不等于同一课程**；用课程 ID 和原始路径区分，不以标题去重。

## 4. 建议课程 JSON 模型（示例，不代表已生成 741 条）

```json
{
  "module": "calligraphy",
  "id": "calligraphy-g1-w02",
  "grade": 1,
  "semester": "下册",
  "week": 2,
  "topic": "长撇",
  "topicStatus": "from_directory",
  "lessons": [
    {
      "id": "calligraphy-g1-w02-01",
      "lessonKey": "1",
      "originalSequence": 1,
      "displayOrder": 1,
      "title": "长撇",
      "originalFileName": "1.长撇.mp4",
      "originalRelativePath": "1.一（下）/1.一（下）/第二周长撇/1.长撇.mp4",
      "objectKey": "calligraphy/g1/w02/01.mp4",
      "validationStatus": "pending_media_check"
    }
  ]
}
```

`objectKey` 仅表示**计划命名规则**，不是已上传的 COS 文件；`topicStatus` 和 `validationStatus` 供导入审查，不代表视频可播放。示例只展现该周的第一课，不是完整周次数据。

## 5. 导入与一致性约束（供 V0.4 执行）

- 区分压缩包和解压文件：五个 `.zip` 不计入 741 个 MP4。
- 兼容原始目录有两层同名年级文件夹的情况；保留原始相对路径，方便定位源文件。
- 目标分布：一年级 78、二年级 78、三至五年级各 195；65 周共 741 个 MP4。
- 校验年级、周次、文件数、可识别源序号、重复源序号、缺失序号、同名课、路径冲突、文件后缀、物理文件是否存在。
- 一/二年级每周 6 条，三/四/五年级每周 15 条；不为异常文件自行补造课程。
- 保留原名：一年级第 13 周 `3..四.mp4` 的 `originalFileName` 不得改写；展示名可先暂拟“四”并标注来源。
- 主题疑点：一年级第 14 周文件夹“横折直钩”与第一课“横折钩”不完全一致；不得自行统一。
- 五年级只有周次目录、无可靠教学主题；V0.1 只显示「第 N 周」，不编造主题。
- 未收到实际 MP4，不可宣称编码、时长、可播或权限已校验。

## 6. 二维码 URL 和文件命名规则（待学校确认粒度）

### 稳定路径层次

- 总站：`/`。
- 书法模块：`/calligraphy`。
- 年级：`/calligraphy/grade/1`。
- 周次：`/calligraphy/grade/1/week/2`。
- 单课：`/calligraphy/grade/1/week/2/lesson/1`。

实际二维码应编码**完整学校正式 HTTPS URL + 上述相对路径**；目前未确认正式域名，故不得用于印刷。不要直接将 COS 视频外链编码为二维码。

### 预定导出清单

`二维码编号 | 入口层级 | 年级 | 周次 | 课程ID | 原始文件名 | 完整链接 | PNG文件名 | SVG文件名 | 测试状态`

建议二维码文件按确定的业务 ID 命名，而不是使用可能重名的汉字标题。示意：`calligraphy-g1-w02.png`、`calligraphy-g1-w02.svg`。

### 长期维护

- 域名及 DNS、云资源由学校长期控制；网站升级时业务 URL 原则上不变。
- 必要时对旧路径实施重定向或兼容映射；**禁止**为重构页面修改已印教材二维码指向的最终资源。
- 打印前对每个正式链接进行自动化校验，并在微信真机上抽查二维码指向、内容和播放行为。
